https://huggingface.co/blog/stable_diffusion

Using num_inference_steps=15 with guidance_scale=7.5 in Stable Diffusion provides a fast generation speed but risks quality degradation, including oversaturation, color shifts, or artifacts, because high guidance at low steps causes incomplete denoising. 

To mitigate these issues:

Lower guidance_scale: Reduce guidance_scale to 5.0 when using low step counts (15–20) to avoid oversaturation. 
Use appropriate schedulers: Switch to DDIM or DPM++ 2M schedulers, which converge better at lower step counts compared to standard DDPM.
Avoid sub-10 steps: Step counts below 15 often result in blurry or incomplete images; if faster speeds are needed, use specialized models like LCM (2–8 steps) instead. 
Clip Skip: clip_skip is a separate parameter that controls how many layers of the CLIP text encoder are skipped during prompt embedding (e.g., clip_skip=2 uses earlier layers). It is independent of step count but can be used alongside these settings to refine prompt adherence and detail.

import torch
from diffusers import StableDiffusionPipeline, DPMSolverMultistepScheduler

model_id = "runwayml/stable-diffusion-v1-5" # or SDXL equivalent
pipe = StableDiffusionPipeline.from_pretrained(
    model_id, 
    torch_dtype=torch.float16,
    variant="fp16" # if available
).to("cuda")

# Configure DPMSolverMultistepScheduler
pipe.scheduler = DPMSolverMultistepScheduler.from_config(
    pipe.scheduler.config,
    algorithm_type="dpmsolver++",
    use_karras_sigmas=True
)

# Generate with guidance
image = pipe(
    prompt="a photo of an astronaut riding a horse on mars",
    num_inference_steps=25,       # Recommended: 25-30 for DPMSolver++
    guidance_scale=7.5,           # Controls prompt adherence
).images[0]

image.save("output.png")
