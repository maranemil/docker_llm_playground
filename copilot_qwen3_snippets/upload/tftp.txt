 install the "HTTP::ServerPSGI" module. Open your terminal and run the following command:

```bash
sudo cpan HTTP::ServerPSGI
```

This will install the module and its dependencies.

Once installed, you can create a simple Perl script to run an HTTP server. Create a new file called "server.pl" and add the following code to it:

```perl
#!/usr/bin/perl
use strict;
use warnings;
use HTTP::ServerPSGI;

my $app = sub {
    my $env = shift;
    my $res  = shift;

    $res->{content_type} = 'text/plain';
    $res->{status} = 200;
    $res->{body} = 'Hello, World!';

    return $res;
};

HTTP::ServerPSGI->new(
    Port => 8080,
    App  => $app,
)->run();
```

Make sure to make the file executable by running:

```bash
chmod +x server.pl
```

Now, you can run the HTTP server by executing the script:

```bash
./server.pl
```

The server will start running on port 8080. You can view it by opening your web browser 
and entering `http://localhost:8080` in the address bar. You should see "Hello, World!" as the response.
I hope this helps you to create an HTTP server using Perl on your Ubuntu system.
