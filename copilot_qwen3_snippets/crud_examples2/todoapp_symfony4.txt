
Okay, let's walk through building an app with CRUD functionality and SQLite database using Symfony 6.  This guide will be a bit more detailed than the previous example.

**1. Project Setup (Similar to 6.1)**

```bash
sudo apt-get install foreman -y
sudo apt-get install libsqlite3-dev
sudo apt-get install libpq-dev  # Crucial for SQLite database support
sudo foreman init
```

* `foreman init`: Initializes the project, sets up the project's root directory, and sets up the basic project structure.

**2. Core Symfony Components**

* **`App`:** (Root Component)  The top-level component of your application.
* **`Controller`:**  Handles requests and logic for a specific feature (e.g., the "Create Product" controller).
* **`Entity`:** Defines the data models (e.g., `Product`, `User`).
* **`Service`:** Manages the CRUD operations (Create, Read, Update, Delete) for your data models.  We'll create a `ProductService` and a `UserService`.
* **`Model`:** Describes the structure of the data (e.g., `Product`, `User`).
* **`Form`:** Defines the input forms used to create and update data.
* **`Bundle` (Optional):** A way to organize related features.  We'll start with a minimal one.

**3. Create a Project**

```bash
symfony new my-product-app
cd my-product-app
```

**4. Create the Application**

```bash
symfony server
```

**5. Create a Controller**

Let's create a `ProductController` to handle creating a new product:

```php
<?php

namespace App\Controller;

class ProductController extends Controller
{
    public function index()
    {
        return view('product_index', ['product' => 'Product1']);
    }
}
```

**6. Create a Model (Product Entity)**

```php
<?php

namespace App\Models;

class Product
{
    protected $id;
    protected $name;
    protected $price;
    protected $description;

    public function __construct(Product $product) {
        $this->id = $product->id;
        $this->name = $product->name;
        $this->price = $product->price;
        $this->description = $product->description;
    }

    public function get_product_id(): int {
        return $this->id;
    }
}
```

**7. Create a Service (ProductService)**

This service handles the CRUD operations.

```php
<?php

namespace App\Services;

class ProductService
{
    public function create_product(Product $product)
    {
        return $product;
    }

    public function get_product(Product $product): ?Product
    {
        return $product;
    }
}
```

**8. Create a Form (ProductForm)**

This form will collect the product's information.

```php
<?php

namespace App\Form;

class ProductForm extends View
{
    public function __construct(ProductService $productService)
    {
        $this->productService = $productService;
    }

    public function validate_name(string $name): bool {
        return filter_var($name, FILTER_SANITIZE_STRING);
    }

    public function validate_price(float $price): bool {
        return $price > 0;
    }
}
```

**9. Create a View (product_index.php)**

```php
<?php

namespace App\Views;

class ProductIndex extends View
{
    public function index()
    {
        return view('product_index', ['product' => 'Product1']);
    }
}
```

**10.  Run the Application**

```bash
symfony server
```

**11. Access the Application**

Open your web browser to `http://localhost:8000/`. You should see the `product_index` view.

**Key Points & Improvements:**

* **Database Integration:**  This example uses a basic `INSERT` and `UPDATE` in the `ProductService`.  In a real-world app, you'd use a database library (like Doctrine or Eloquent) to interact with your database.
* **Error Handling:**  Add error handling (e.g., check for valid input) to your controllers and services.
* **Security:**  Implement better security measures like input validation, sanitization, and protection against common web attacks.
* **Routing:** You'll need to configure your application's routing to map URLs to the correct controllers.
* **Data Validation:** Implement more robust data validation in your Forms to ensure data integrity.
