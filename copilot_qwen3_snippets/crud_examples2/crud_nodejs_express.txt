

Okay, let's create a basic CRUD (Create, Read, Update, Delete) system for an event app using Node.js, Express, and SQLite.  This will be a simplified example to illustrate the core concepts.

**1. Project Setup:**

First, create a new directory for your project:

```bash
mkdir event-app
cd event-app
npm init -y # Initializes a package.json file
```

**2. Install Dependencies:**

Open your terminal and install the necessary packages:

```bash
npm install express sqlite3
```

**3. Code (app.js):**

```javascript
const express = require('express');
const sqlite3 = require('sqlite3').verbose(); // Import SQLite3 module

const app = express();
const port = 3000;

// Connect to the SQLite database
const db = new sqlite3.Database('event_data.db', (err) => {
  if (err) {
    console.error('Error connecting to the database:', err);
    process.exit(1); // Exit if connection fails
  }

  // Create table if it doesn't exist
  db.run(`
    CREATE TABLE IF NOT EXISTS events (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      title TEXT,
      description TEXT,
      date TEXT,
      location TEXT,
      price REAL,
      category TEXT
    )
  `);

});


// --- Routes ---

// GET /events - List all events
app.get('/events', (req, res) => {
  const db = new sqlite3.Database('event_data.db', (err) => {
    if (err) {
      console.error('Error connecting to the database:', err);
      return res.status(500).send('Error listing events');
    }

    let query = 'SELECT * FROM events';
    const rows = db.all(query); // Use all() for a safe fetch

    res.json(rows);
  });

  // GET /events/:id - Get details of a specific event
  app.get('/events/:id', (req, res) => {
    const id = parseInt(req.params.id);
    const db = new sqlite3.Database('event_data.db', (err) => {
      if (err) {
        console.error('Error connecting to the database:', err);
        return res.status(500).send('Error retrieving event');
      }

      const query = 'SELECT * FROM events WHERE id = ?';
      const args = [id];
      db.all(query, args, (err, row) => {
        if (err) {
          console.error('Error fetching event:', err);
          return res.status(500).send('Error retrieving event');
        }

        if (!row) {
          return res.status(404).send('Event not found'); // Handle cases where the ID doesn't exist
        }

        res.json(row);
      });

    });


  // POST /events - Create a new event (requires authentication/registration)
  app.post('/events', (req, res) => {
    const { title, description, date, location, price, category } = req.body;

    if (!title || !description || !date || !location || !price || !category) {
      return res.status(400).send('Missing required fields.');
    }

    // Basic validation (you'd likely want more robust validation)
    if (price < 0) {
        return res.status(400).send("Price must be non-negative.");
    }


    const db = new sqlite3.Database('event_data.db', (err) => {
      if (err) {
        console.error('Error connecting to the database:', err);
        return res.status(500).send('Error creating event');
      }

      // Insert data into the table
      db.run(`
        INSERT INTO events (title, description, date, location, price, category)
        VALUES (?, ?, ?, ?, ?, ?)`, [
          title,
          description,
          date,
          location,
          price,
          category
        ]);

      res.status(201).send('Event created successfully'); // 201 Created status code
    });
  });


  // DELETE /events/:id - Delete an event
  app.delete('/events/:id', (req, res) => {
    const id = parseInt(req.params.id);
    const db = new sqlite3.Database('event_data.db', (err) => {
      if (err) {
        console.error('Error connecting to the database:', err);
        return res.status(500).send('Error deleting event');
      }

      // Find and delete the event
      db.run(`DELETE FROM events WHERE id = ?`, [id]);

      res.status(204).send(); // 204 No Content - successful deletion
    });
  });


  app.listen(port, () => {
    console.log(`Server listening on port ${port}`);
  });
}
```

**4. Explanation:**

* **`express`:**  The framework for the server.
* **`sqlite3`:** The SQLite driver.
* **`app.get('/events', ...)`:** This route handles GET requests to `/events`. It retrieves all events and returns them as JSON.
* **`app.get('/events/:id', ...)`:**  This route handles GET requests to `/events/:id`, where `:id` is a path parameter. It fetches the details of a specific event based on its ID, and returns it as JSON.
* **`app.post('/events', ...)`:** This route handles POST requests to `/events`.  It allows you to create new events (you’d need user authentication/registration for this). It takes data from the request body (`req.body`) and creates a new row in the database.
* **`app.delete('/events/:id', ...)`:** This route handles DELETE requests to `/events/:id`.  It deletes the event with the given ID.

**5. How to Run the Code:**

1.  Save the code as `app.js`.
2.  Open your terminal, navigate to the project directory (`event-app`), and run: `node app.js`
3.  You should see "Server listening on port 3000" in the console.

**6. Key Concepts Illustrated:**

*   **Routes:** Define how different URLs are handled (GET, POST, DELETE).
*   **Middleware:**  (Not shown here but important for real apps)  You might use middleware to perform tasks like authentication or logging.
*   **Request/Response Handling:**  How the server receives data from clients and sends responses back.
*   **Data Serialization (JSON):** The `res.json()` method converts JavaScript objects into JSON strings, which are then sent as a response.
*   **Error Handling:** Basic error handling is included for missing data and invalid input.
