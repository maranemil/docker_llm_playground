Demo 3 (Automation Bench
Step 1: Check the current price on [product name] and save it to /opt/data/price_baseline.json along with today's date.
Step 2: Check the current price on [same product URL] again and compare it to what's saved in /opt/data/price_baseline.json. If the price has changed, send me a message on Telegram with the old and new price, and log the change with a timestamp to /opt/data/price_log.csv.

Demo 4 (3D game

Keep the graphics intentionally simple, basic shapes and flat colors are fine. Include basic WASD or arrow-key movement, a spacebar or click to fire the web line, physics-based swinging momentum, and a simple scoring or distance system. Save it as a single HTML file with embedded JavaScript at /opt/data/spider-swing.html. Load three.js from a CDN. Do not take screenshots, do not install a browser, do not visually verify the page — just write the file and stop.
