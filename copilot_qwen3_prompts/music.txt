https://www.youtube.com/watch?v=dMb4xFw9D4A
https://www.youtube.com/watch?v=YL5e3ae7wxY
-------------------------
Build a VST3/AU instrument plugin and create a name for it (developer name: Hitclub DSP). A mono-focused lead/bass synth with a colorful, knob-heavy Ul inspired by Nexus - every parameter is a custom-drawn glowing rotary knob (no scary flat UI), color-coded by section, with live-updating visual displays for oscillator waveforms, filter curve, and ADSR envelope shapes. **Voice engine:** Mono/Legato/Poly switch + a Portamento/Glide knob (with Always vs Legato-only mode).
**Sound engine:** 2 oscillators (saw/square/tri/sine/PWM) + sub osc + noise, unison/detune stacking for fat mono tones, multi-mode filter (LP/HP/BP/notch, 12/24dB) with drive and key tracking, 2 ADSR envelopes (amp + filter) with visual curve displays, 2 LFOs with tempo sync.
**Effects chain:** Bitcrusher/Distortion
Chorus → Delay → Reverb. The bitcrusher must be a unique "colored" character effect (bit-crush + sample-rate reduction + asymmetric waveshaping + resonant tone filter), not a generic clipper.
